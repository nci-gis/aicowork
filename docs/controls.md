# Controls catalogue — evidence mapped to controls

_Every control names the threat it addresses, where it is implemented, the test or artifact that evidences it, and a framework reference. This is evidence for a reviewer, **not** a compliance claim. Framework references: OWASP Top 10 for LLM Applications 2025 (LLM01–LLM10); OWASP Top 10 for Agentic Applications 2026 (ASI01–ASI10, item names from secondary sources); ISO/IEC 27001:2022 Annex A (IDs from the standard's published control list; verify against your licensed copy); NIST AI RMF / AI 600-1 functions._
