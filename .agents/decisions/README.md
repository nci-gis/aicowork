# Design decisions

_Development records (`.agents/`): never shipped, never part of the kernel._ Each file says what was decided, why, and when to revisit it. They were written while the kernel was developed inside its first owner's instance, so some refer to files there (`05_results/`, `06_logs/`, `09_decisions/`) that this repository does not contain; those are kept privately by that owner. The decisions themselves stand on the text here.

Earlier records (2026-08, written in Vietnamese and full of one owner's context) are not carried over. What they decided is in `99_system/PHILOSOPHY.md` and `CONVENTIONS.md`.
