# Module `7habits`

Adopted under the Framework Adoption Contract (PHILOSOPHY): one folder (this one), two fields (`q`, `role`), one signal (Q2 share), one prompt (weekly "Roles & goals").

- `roles.template.md` — skeleton for the owner's "## Roles" section in `03_personas/me.md`.
- Template fragments: the kernel templates wrap habit-specific lines in `<!-- module:7habits -->` … `<!-- /module -->`. With the module off, those blocks are dropped when a note is created.

Enable or disable in `aicowork.yaml` → `modules:`.
